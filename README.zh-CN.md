# Code2MP4

**用自己的材料和喜欢的 Agent，制作能够持续修改的视频。**

Code2MP4 是一个桌面视频创作产品，面向知识、个人 IP 和产品内容创作者，围绕讲解表达、可编辑工程与持续改稿，把素材、画面、旁白、字幕和 MP4 交付连接起来。

## 产品面向的工作

- 把知识、数据、过程和产品想法转成视频表达。
- 使用自己的素材，与兼容的外部 Agent 协作制作。
- 保留可编辑工程，用于预览、修改和隔天继续创作。
- 组织画面、旁白、字幕与时间关系，完成 MP4 交付。

具体可用功能、兼容 Agent、操作系统与已知限制，按每个实际发布的构建分别说明。产品方向不等于所有能力已经发行。

## 从开源实验到桌面产品

Code2MP4 最初以一个小型开源实验项目起步。此后，我们另行启动了当前桌面产品的独立开发，并持续迭代。

早期代码保留在 [legacy-open-source 历史分支](https://github.com/code2mp4/code2mp4/tree/legacy-open-source)，继续按原 Apache License 2.0 提供。它是历史原型，不作为当前产品的另一条持续维护版本。旧安装命令和示例只适用于该原型。

默认分支保存公开文档与发布元数据。GitHub 自动生成的本分支源码压缩包包含这些公开材料；桌面安装包在 [Releases](https://github.com/code2mp4/code2mp4/releases) 中单独发布。
