## Independently developed desktop product

After the initial experiment, the current Code2MP4 desktop product was independently developed in a separate codebase and has continued to evolve. Its application source is closed-source.

The existing repository address now serves as the public product home. Current product documentation, feedback, and published installers belong here; the early implementation is preserved in the historical branch.

Independently developed does not mean that the desktop product has no third-party dependencies. The notices accompanying each actual build describe the components used by that build.

## Compatibility and versions

The early prerelease is not an installer or compatibility guarantee for the current desktop product. Importing old projects or upgrading between different implementations must be explicitly supported by the relevant desktop release before being relied on.

历史原型不再承诺新增功能或兼容性维护。它不是当前产品的另一条持续维护版本。旧工程导入、版本升级与平台兼容，以当前实际发行版本明确支持的范围为准。

独立开发不表示没有第三方依赖；各实际安装包应随附其适用的组件声明。
