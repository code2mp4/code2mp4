# Getting started

[简体中文](#简体中文) · [Downloads](downloads.md)

## Before installing

Check [Downloads](downloads.md) for an actual desktop installer. No current installer is published here yet. Supported platforms, compatible Agents, and installation requirements will be listed per build.

Cloning this default branch gives you public documentation. The early prototype's Node.js and pnpm setup belongs to the [historical source](history.md), not the current desktop installation path.

## Creation workflow

Once a compatible desktop build is available:

1. Install the build matching your operating system and processor.
2. Configure a compatible external Agent using the build's instructions.
3. Start a project with your materials, intended audience, video format, and goal.
4. Review the resulting picture, narration, subtitles, and timing; request changes to the editable project.
5. Export the current revision and keep the project for later editing.

The exact commands, controls, and supported operations are documented with the relevant release. Code2MP4 does not include a model subscription or bundled API credits. Third-party Agent and model access are configured separately.

## Your materials

Use materials you have permission to process and publish. External Agents and model providers may receive content that you send to them. Review the selected tools' data handling and the release's documented behavior when deciding which material to use.

## 简体中文

### 安装前

先在[下载页](downloads.md#简体中文)确认实际可用的桌面安装包。当前尚未在本仓发布安装包；支持系统、芯片、Agent 和安装要求按构建分别说明。

克隆默认分支会得到公开文档。旧原型的 Node.js、pnpm 等源码运行步骤保留在[历史版本](history.md#简体中文)，不作为当前桌面产品的安装方法。

### 制作流程

当兼容的桌面构建可用后，按该版本说明安装并配置外部 Agent，再提供素材、目标观众、视频规格和希望讲清楚的问题。围绕同一可编辑工程预览画面、听取声音、修改字幕与节奏，最后导出当前修订并保留工程供后续修改。

具体操作与支持范围以该版本文档为准。Code2MP4 不附带模型订阅或 API 额度，外部 Agent 和模型服务需分别配置。使用自己的材料时，也需考虑所选外部工具的数据处理方式。
